## Project Description

This project explores JavaScript DOM manipulation and event handling. It includes practical exercises and an interactive To-Do List application.

Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- DOM element selection and manipulation
- DOM traversal
- Creating and removing HTML elements
- Event listeners and event delegation
- Keyboard shortcuts
- Form validation
- Interactive To-Do List
- Add, complete and delete tasks
- Filter tasks by status
- Clear completed tasks
- Responsive design
- Five daily JavaScript challenges

## How to Run

1. Clone or download this repository.
2. Open "index.html" in a web browser.
3. Add tasks using the input field.
4. Mark tasks as completed or delete them.
5. Use the filters to view all, active or completed tasks.

## Lessons Learned

- How JavaScript interacts with HTML through the DOM.
- How to select and traverse elements.
- How to create, update and remove elements dynamically.
- How to use event listeners and event delegation.
- How to validate forms.
- How to build interactive web applications.

## Challenges Faced

- Understanding DOM traversal.
- Working with event bubbling and delegation.
- Handling form validation.
- Connecting JavaScript functionality to HTML elements.
- Building an interactive application.
